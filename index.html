📋 LE RÉCAPITULATIF (À lire en 1 minute)

Si vous ne lisez qu'une chose de ce document, lisez ceci. Voici les 7 étapes que vous aurez à réaliser.

  1. Installer l'application sur votre ordinateur (une seule fois).
  2. Importer la liste des enfants au format CSV (une seule fois, en début d'année).
  3. Mettre à jour la liste au fil de l'année (arrivées, départs, changements).
  4. Imprimer les fiches de présence (toutes les 2 semaines, c'est une bonne pratique).
  5. Saisir le pointage en lisant les fiches (rechercher les garderies occasionnelles et les retards).
  6. Exporter la sauvegarde JSON vers le Drive (une fois par mois, obligatoire).
  7. Transmettre le récapitulatif au trésorier (Ctrl+P / ⌘+P).

Les étapes 3 à 7 sont répétitives. Les étapes 1 et 2 ne se font qu'une seule fois.

📖 AVANT-PROPOS : Comment ce document a été pensé

Personne n'aime lire une documentation. Nous le savons.

Ce document a été conçu pour être le plus simple possible, avec une logique : apprendre en tâtonnant. L'application est faite pour être intuitive.

Si vous rencontrez une difficulté, vous pourrez vous référer aux détails ci-dessous. Mais la plupart du temps, vous n'aurez pas besoin de lire tout ça : le récapitulatif en 7 étapes suffit pour démarrer.

Les règles d'or :

  • Google Drive est votre coffre-fort (stockage).
  • Votre ordinateur est votre espace de travail (l'application tourne en local).
  • L'application sauvegarde automatiquement dans votre navigateur. Mais un export mensuel vers le Drive est obligatoire pour ne rien perdre.
  • L'application fonctionne 100% hors ligne. Seuls le téléchargement initial et l'export vers le Drive nécessitent Internet.

(Cette application a été conçue avec l'aide de l'IA DeepSeek.)

🚀 ÉTAPE 1 : Installation (UNE FOIS)

  1. Rendez-vous sur le Google Drive de l'association. Vous y trouverez le dossier de l'application. Google Drive le propose au téléchargement sous forme de fichier .zip.
  2. Téléchargez ce fichier .zip sur votre ordinateur.
  3. Faites un clic droit dessus et choisissez « Extraire tout » (ou « Décompresser »).
  4. Placez le dossier extrait là où vous le souhaitez (par exemple sur votre Bureau).

Créer un raccourci :

  • Ouvrez le dossier extrait. Vous verrez un fichier nommé index.html.
  • Faites un clic droit dessus → « Envoyer vers » → « Bureau (créer un raccourci) ».
  • Renommez ce raccourci en « Garderie ». C'est le seul raccourci dont vous aurez besoin.

📂 ÉTAPE 2 : Importer la liste des enfants (UNE FOIS, en début d'année)

En début d'année, vous n'avez pas encore de sauvegarde JSON. Ce que vous avez, c'est le fichier Excel fourni par l'école (la liste des élèves).

  1. Ouvrez ce fichier Excel et faites une copie.
  2. Supprimez toutes les colonnes inutiles pour ne garder que 3 colonnes dans cet ordre :
    • Colonne 1 : Nom de l'enfant
    • Colonne 2 : Prénom de l'enfant
    • Colonne 3 : Type de garderie (Matin uniquement / Soir uniquement / Matin et soir / Non inscrit)
  3. Enregistrez ce fichier au format CSV (séparé par des points-virgules).
  4. Dans l'application, allez dans l'onglet « Enfants » et cliquez sur « Importer un tableau (CSV) ». Sélectionnez votre fichier.
  5. Vérifiez l'aperçu, puis validez. Votre liste est créée.

Si vous reprenez l'outil d'une personne qui vous l'a transmis, vous n'avez pas besoin de cette étape. Il vous suffit d'aller dans « Sauvegardes » et d'importer le fichier JSON qu'elle vous a laissé.

👶 ÉTAPE 3 : Mettre à jour la liste (RÉPÉTITIF)

L'école vous fournit une liste en début d'année, mais elle n'est plus mise à jour par la suite. Vous serez avertis par mail des arrivées et des départs. C'est donc à vous de mettre à jour l'application.

  • Allez dans l'onglet « Enfants ».
  • Cliquez sur « Ajouter » pour créer un nouvel enfant.
  • Si un enfant part, cliquez sur la petite poubelle à côté de son nom.
  • Si un enfant change de créneau, modifiez son type d'inscription directement dans le tableau.
⚠️ Attention avant de supprimer un enfant :
Si un enfant a été en garderie et que des sommes sont encore dues, supprimer sa fiche effacera tous ses enregistrements de pointage.
Avant de le supprimer, vérifiez bien que les impressions d'écran (ou les PDF) ont été faites, notamment si la famille n'a pas encore réglé ce qu'elle doit.

⚙️ ÉTAPE 4 : Vérifier les tarifs (UNE FOIS, en début d'année)

Avant de commencer le pointage, assurez-vous que les tarifs sont à jour.

  • Allez dans l'onglet « Tarification ».
  • Vérifiez le prix du quart d'heure de retard.
  • Vérifiez le prix de la garderie occasionnelle.

C'est sur ces montants que l'application va calculer tout le reste. Si l'association a décidé d'augmenter les tarifs, c'est ici qu'il faut le faire.

🖨️ ÉTAPE 5 : Imprimer les fiches de présence (RÉPÉTITIF)

Bonne pratique : imprimez les fiches toutes les deux semaines.

Notre retour d'expérience montre qu'imprimer trop de fiches à l'avance conduit à devoir les jeter (ou les modifier à la main) à chaque arrivée ou départ. Deux semaines représentent généralement 8 fiches à imprimer.

Vous pouvez vous aider du calendrier fourni par l'école en début d'année pour déterminer le nombre de fiches à imprimer à l'avance.

  1. Allez dans l'onglet « Impression ».
  2. Cliquez sur « Télécharger en PDF ».
  3. Imprimez le PDF et remettez-le aux surveillantes.
  4. Les parents le rempliront à la main (heure d'arrivée, signature, heure de départ).

✍️ ÉTAPE 6 : Le pointage (RÉPÉTITIF - C'est le cœur du métier)

C'est ici que vous allez entrer les informations récoltées sur les fiches de présence.

Avant de commencer, posez-vous deux questions en lisant les fiches :

  • Y a-t-il eu des garderies occasionnelles ? (Un enfant non inscrit qui est venu, ou un enfant inscrit un jour où il ne devait pas l'être).
  • Y a-t-il eu des retards ? (Un parent qui est venu chercher son enfant après l'heure).

Grâce à ces deux questions, vous allez pouvoir remplir sereinement la partie pointage sans rien oublier.

Comment faire :

  1. Allez dans l'onglet « Pointage ».
  2. Sélectionnez le mois concerné.
  3. Cliquez sur « Ajouter un enfant au mois » pour chaque enfant concerné.
  4. Pour chaque enfant, ajoutez les dates, choisissez le moment (Matin, Soir, Matin et Soir) et indiquez le retard (+15 min, +30 min, etc.).
  5. Le tarif se calcule tout seul. Ne vous prenez pas la tête, l'application applique les règles.
  6. Une fois le mois terminé, cliquez sur « Marquer comme traité ».
Note : cela ne change pas de mois automatiquement. Cela permet simplement de colorer le mois en vert, et de faire en sorte que l'application s'ouvre sur le mois suivant non traité la prochaine fois que vous la lancerez.

💾 ÉTAPE 7 : La sauvegarde mensuelle (RÉPÉTITIF - OBLIGATOIRE)

Les données sont stockées dans votre navigateur. Si vous videz votre cache ou changez d'ordinateur, vous perdez tout.

Une fois par mois, vous devez faire une sauvegarde vers le Drive.

  1. Dans l'application, allez dans l'onglet « Sauvegardes ».
  2. Cliquez sur « Exporter la sauvegarde (JSON) ».
  3. Un fichier sauvegarde-garderie-AAAA-MM-JJ-HHhMM.json se télécharge.
  4. Déplacez ce fichier sur le Google Drive de l'association (dans le dossier prévu à cet effet).

Conseil : gardez une seule sauvegarde par mois (pas besoin d'en faire tous les jours).

🔍 ÉTAPE 8 : Transmettre les informations (RÉPÉTITIF)

Pour le trésorier :

  • Dans l'onglet « Pointage », affichez le mois concerné.
  • Faites Ctrl + P (Windows) ou ⌘ + P (Mac) depuis votre navigateur.
  • Imprimez ou enregistrez en PDF la page qui s'affiche. C'est un document propre, lisible, avec tous les enfants et les montants du mois.

Pour un parent (s'il demande le détail) :

  • Cliquez sur l'icône 📷 (appareil photo) à côté du nom de l'enfant dans l'onglet Pointage.
  • L'application télécharge une image .jpg de la fiche de cet enfant pour ce mois.
  • Vous pouvez envoyer cette image par mail ou WhatsApp au parent.

Pour les preuves (photos des fiches papier) :

  • Pensez à photographier les fiches de présence papier remplies par les parents.
  • Rangez ces photos dans un dossier Preuves sur le Drive, à côté de l'application.
  • Si un parent conteste, vous aurez la preuve papier ET l'image générée par l'application.

🛡️ SÉCURITÉ ET TRANSMISSION (UNE FOIS)

Le code de cette application est en accès libre. C'est une force : n'importe qui peut le lire ou le modifier (avec l'aide d'une IA, par exemple) pour l'adapter aux besoins futurs.

La règle d'or : Toujours garder une version stable
Avant de faire la moindre modification du code :
  • Créez un sous-dossier sur le Drive nommé /Version_Stable_[Date].
  • Copiez dedans les 3 fichiers (index.html, styles.css, app.js) + le dernier JSON.
  • Ne touchez plus à ce dossier. C'est votre filet de sécurité.
  • Si les modifications futures cassent quelque chose, il suffit de restaurer ce dossier stable.
